# ![](images/icon/TexTra_cyan44.png) TexTra Trados

![](images/001.png)

**TexTra Trados**は <br>
SDL社、翻訳支援アプリ「Trados」に<br>
**「みんなの自動翻訳」** を利用した翻訳機能を提供するアドインです。<br>

**TexTra Trados** is an add‑in for SDL's translation support application "Trados" <br>
that provides translation functionality using **"Min'na no Jidou Hon'yaku"**.<br>

---

## 📥インストール Install

アドインファイル、TexTraTrados.sdlpluginを<br>
本画面の「Releases」からダウンロードして実行してください。<br>
https://github.com/NICT-Dev/TexTra-Trados/releases<br>

ダウンロードしたアドインファイルを<br>
Tradosのアドインフォルダに配置してください。<br>
（アドインフォルダは
、Tradosインストール後、自動で作成されています。）<br>
<br>
アドインフォルダ、Trados2024の場合<br>
%AppData%\Trados\Trados Studio\18\Plugins\Packages<br>
![](images/002.png)

Tradosを起動した際、<br>
「署名のないプラグインを読み込もうとしていることが検出されました。」と表示されます。<br>
「はい」を選択してください。<br>
※RWS社による署名がないためです。<br>
![](images/003.png)

## ⭐️GithubでTradosアドインを公開する理由
本来、Trados用のアドインは<br>
RWS AppStoreで公開すべきですが、<br>
現在、開発者自身でのアップロードが制限されています。<br>
そのため、Githubで公開しています。<br>

## ⭐️Reasons for publishing the Trados add‑in on GitHub:
Originally, Trados add‑ins should be published on the RWS AppStore.  
However, developers are currently unable to upload their own plug‑ins.  
For this reason, the add‑in is published on GitHub instead.
